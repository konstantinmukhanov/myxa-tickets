# Билеты MYXA

Бумажные билеты Studio MYXA: служебный Telegram-бот на Google Apps Script и QR-сканер для продажи и контроля на входе.

- `apps-script/Билеты.gs` — код бота; живёт в проекте Apps Script таблицы записи рядом с «Бот.gs» (напоминалка) и «Расчёт.gs».
- `index.html` — страница сканера (Telegram Mini App), публикуется через GitHub Pages:
  https://konstantinmukhanov.github.io/myxa-tickets/
- `templates/make_template.py` — заготовка макета билетов (A4, 6 билетов 66×143 мм).
- `logo/` — аватар бота.
- `test/` — проверка на имитации Apps Script: `npm test`; сквозная проверка сканера в Chromium: `npm run test:ui`.

## Установка

### 1. Создать бота
В Телеграме @BotFather → `/newbot` → имя, например «MYXA билеты», ник, например `myxa_tickets_bot`. Скопировать токен.

### 2. Код
Таблица записи → Расширения → Apps Script (проект, где уже лежат «Бот.gs» и «Расчёт.gs»).
1. «+» → Скрипт → назвать `Билеты` → вставить содержимое файла `apps-script/Билеты.gs` → сохранить.
2. В «Бот.gs» найти строку `function doPost(e) {` и сразу под ней вставить одну строку:
   ```
   if (e && e.parameter && e.parameter.tk) return tkDoPost(e);
   ```
   Больше в «Бот.gs» ничего не менять.

### 3. Свойства скрипта
Настройки проекта → Свойства скрипта → добавить:
- `TK_BOT_TOKEN` — токен из шага 1;
- `TK_SCANNER_URL` — адрес страницы сканера (шаг 4).

`WEBAPP_URL` уже есть — его использует напоминалка, служебный бот работает через тот же адрес.

### 4. Страница сканера
Страница — `index.html` этого репозитория. GitHub Pages: Settings → Pages → Source «Deploy from a branch», ветка `main`, папка `/ (root)`.
Адрес для `TK_SCANNER_URL`: `https://konstantinmukhanov.github.io/myxa-tickets/`

### 5. Опубликовать новую версию
«Начать развёртывание» → «Управление развёртываниями» → карандаш → «Версия: Новая версия» → «Развернуть».
Адрес не меняется. Это обязательно: изменился doPost.

### 6. Запустить настройку
В редакторе выбрать функцию `tkSetup` → «Выполнить». Google попросит новые разрешения (Презентации, Диск, внешние запросы) — согласиться.
В журнале появится одноразовая ссылка администратора — открыть её на телефоне и нажать «Старт».

### 7. Показы и макеты
- Лист «Показы»: проверить даты, время, цены и вместимость (заполнены примером декабря в KC Grad).
- В колонку «Макет» вставить ссылку на презентацию-макет: «Макет билета — Финдус» для строк Финдуса, «Макет билета — Клаус» для Клауса (папка «MYXA · макеты билетов» на Диске).

## Макет
Можно менять всё оформление, фон, шрифты и расположение. Бот ищет только метки:
- `{{QR_1}}` … `{{QR_6}}` — фигура (квадрат), в которой написана только эта метка. Бот заменит её на QR-код того же размера.
- `{{КОД_1}}` … `{{КОД_6}}` — код билета текстом (на случай, если QR не прочитается).
- `{{СПЕКТАКЛЬ}}`, `{{ДАТА}}`, `{{ВРЕМЯ}}`, `{{ПЛОЩАДКА}}`, `{{ТИП}}`, `{{ЦЕНА}}` — подставляются в любой текст.

Номер у QR и кода одного билета должен совпадать. Сколько меток QR на первом слайде — столько билетов на листе.
Бот берёт первый слайд макета, остальные слайды можно использовать для заметок.
Проверить макет без выпуска билетов — команда `/preview`.

## Команды
Все: `/scan` — сканер, `/shows` — продажи по показам.
Админ: `/new` — выпустить билеты (PDF), `/preview` — образец, `/report` — наличные по показам и продавцам,
`/invite` — пригласить, `/team` — команда, `/void КОД` — аннулировать потерянный билет.

PDF выпусков сохраняются на Диске в папке «MYXA · билеты».
